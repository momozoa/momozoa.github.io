# 음악 플레이어 구현 계획

## 목표
- 웹 기반의 간단한 음악 플레이어 구현
- 로컬/외부 mp3 파일 재생, 재생목록, 일시정지, 다음/이전 곡, 볼륨 조절 등 기본 기능 제공

## 주요 기능
- 오디오 파일 재생/일시정지/정지
- 재생목록(Playlist) 관리
- 곡 넘김(이전/다음)
- 볼륨 조절 및 음소거
- UI: 곡 정보, 진행 바, 컨트롤 버튼

## 파일 구조
- index.html: 메인 페이지
- main.js: 플레이어 로직
- style.css: 스타일
- docs/: 문서 폴더

## 검증 계획
- 각 기능별 수동 테스트 (재생, 정지, 곡 넘김, 볼륨 등) **완료**
- UI 요소 정상 동작 확인 **완료**

---

## 2025년 12월 최신화
- SVG 아이콘 기반 컨트롤 버튼(재생/정지/이전/다음/볼륨/음소거)
- 플레이리스트 selected/hover 효과 통일(현재 곡 강조)
- 실시간 Web Audio API 비주얼라이저(막대, glow, 평탄화)
- Glassmorphism/Neon UI 스타일 적용
- 팝업 크기(450x700) 및 스크롤바/불릿/간격 등 UI 개선
- CSS 구조 표준화 및 중복 제거
